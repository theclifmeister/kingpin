# Cash formatting

**Cash formatting** (#82): `internal/format` is the one place a number is written, for the UI and the report alike: `format.Cash` compacts totals (`$45K`, `$1.2M`, `$3.4B`) for the title bar, dashboard, report and run summary; `format.Money` keeps exact figures for itemised amounts (fees, wages, a purchase); `format.Price` is per-unit (cents under $1,000); `format.Arrow` is `→` for a change (`14 → 17`, never `->`), `format.Plural` is `1 corner` / `3 corners` (`format.Plurals` the bare plural, with the irregulars the game counts: `city` / `cities`, `person` / `people`, `box` / `boxes`, a two-word noun on its last word) and `format.A` is a noun with its article (`a runner`, `an enforcer`). `internal/ui/format.go` keeps `cash()`, `money()`, `price()` and `plural()` as thin aliases, and `sim/news/news.go` builds the report's money and arrow lines with the package (no `$%d` anywhere in it). **Tables** are one component, `ui/table.go`: `table(cols, rows, cursor, width)` draws declared columns (`col{title, kind, width}`, kinds `text, int, cash, money, price, pct, days, bar, dial`) with one number format per column, text left and numbers right, the header in `Subtle`, the cursor's row as `▸` + `Selected` across the row, and the last text column giving way to the width; a cell may be wrapped in `styled`, `approx` (`~40`) or `signed` (`+8%`), a bar column takes a `gauge` or a `spark`, a dial column an `order`, a days column a `day` (`d0`), and a row may start with a `mark` for its gutter. A column exists only if every row has it, so a note is a titled status column or leaves the table. `tableHook` lets `TestTablesAreConsistent` run `checkTable` over every table the rich fixture renders (`richFixture` in `ui_test.go`, shared with `TestRendersAtCommonSizes`).
