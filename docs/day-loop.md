# Day loop

**Day loop.** `game.Clock.EndDay` (`internal/game/clock.go`) builds a `Tick` with a per-day RNG from `game.RNGFor(seed, day)`, steps every `Simulation` in the fixed order `world -> market -> logistics -> territory -> rivals -> crew -> heat -> law -> laundering -> reputation -> news` (the world first since #44: an incident lands on the world before anything reads it, `docs/incidents.md`), then clears the player's per-day scratch as one unit (`World.Today`, `World.ClearToday`, #144: the orders, never the standing ones (#114), the buys bar the morning's supply-contract receipts, which it keeps through the day for the cart (#113, the one exception, `supplied`), lie-low, the strike, the investigation, upgrades bought, the proposal, accepted offers, abandoned corners, funding, deliveries, undercuts, moves, houses bought, the scout, the tip and the buy-off (#70); the sims' own per-day tallies, `Dilemmas.Answered`, `Crew.HiredToday`, `FiredToday` and `PaidOffToday` and a market's `BoughtToday`, stay on their sims' state and the clock clears them beside it) and publishes the tick's events on the `events.Bus`. Because RNG is derived from `(seed, day)`, nothing about randomness is saved and a run is reproducible from its seed; `TestDeterministicForSeed`, `TestDistributorIsDeterministicAndSaves` and `TestSaveRoundTripIsDeterministic` enforce this. The shape rules have their own guards: `TestStashHasNoWriters` (`game/stock_test.go`, #144) greps every non-test file under `cmd/` and `internal/` for a write into a stash map outside `game/world.go`, so `AddStock` and `TakeStock` stay the only way stock moves, the way `TestThemeIsTheOnlyStylist` keeps the styles in `theme`. `TestSimsWriteOnlyTheirOwnState` (`sim/sim_test.go`, #144) greps every non-test file under `internal/sim/` for an assignment or an alias into the world (`w.X... =`, `&w.X`) and allows a sim only its own state (the map's row: the world sim `Incidents`, its effects applying in `game.ApplyIncident`; the heat sim `Heat`, a city's `Heat`, `Houses` and `FallsTaken`; the law `Law`, a city's `Pressure` and `Goodwill`; and so on), the till (`Player.DirtyCash`, `CleanCash`), `Stats` and `Over`, with the three cross-sim writes the docs rule on named as exceptions so the list can only shrink (the lieutenant's walk booking the rival's flip, `crew/lieutenant.go`; the audit's flip, `laundering.go`; the connect's collector hurting your enforcer, `market/suppliers.go`); what a sim writes through a pointer it was handed (a `*City`, a `*House`, a `*Corner`) is the same rule by convention. `TestSeedDigest` (`harness/digest_test.go`, #144) plays the boss sixty days on seed 7 with the incident table boxed (#44, as every harness run is) and pins a digest of the whole world after every one of them (a reflective walk in a fixed order, floats to six decimals so an arm64 build's fused multiply-add cannot move it), so a draw added to the home stream, a sim slotted between two others or a number moved fails one test that names the day it moved and prints the new list to pin; a PR that moves it says why. Sims must stay deterministic given `(World, Tick)`. `Tick.RNG` is the home city's stream; anything that happens away from home (another city's market and robberies, the road) rolls on a side stream, `Tick.Sub(name)`, derived from the seed, the day and the name, so a run that never leaves Eastside replays exactly as it did before the second city existed and every seed-pinned balance number survived #30 unchanged. Keep it that way: a sim that adds dice for the second city draws them from a `Sub`, and so does the law (`Tick.Sub("law")` for an election and a new chief), so the home stream survived #41 too, and the world sim (`Tick.Sub("incidents")`, its only dice), so a run with the table boxed is the run before #44.
