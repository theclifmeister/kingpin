# Day loop

**Day loop.** `game.Clock.EndDay` (`internal/game/clock.go`) builds a `Tick` with a per-day RNG from `game.RNGFor(seed, day)`, steps every `Simulation` in the fixed order `market -> logistics -> territory -> rivals -> crew -> heat -> law -> laundering -> reputation -> news`, then clears the player's per-day scratch (orders, never the standing ones (#114), buys bar the morning's supply-contract receipts, which it keeps through the day for the cart (#113), lie-low, strike, hires, fires, upgrades bought, the proposal, accepted offers, abandoned corners, funding, the scout, the tip and the buy-off (#70)) and publishes the tick's events on the `events.Bus`. Because RNG is derived from `(seed, day)`, nothing about randomness is saved and a run is reproducible from its seed; `TestDeterministicForSeed`, `TestDistributorIsDeterministicAndSaves` and `TestSaveRoundTripIsDeterministic` enforce this. The shape rules have their own guards: `TestStashHasNoWriters` (`game/stock_test.go`, #144) greps every non-test file under `cmd/` and `internal/` for a write into a stash map outside `game/world.go`, so `AddStock` and `TakeStock` stay the only way stock moves, the way `TestThemeIsTheOnlyStylist` keeps the styles in `theme`. Sims must stay deterministic given `(World, Tick)`. `Tick.RNG` is the home city's stream; anything that happens away from home (another city's market and robberies, the road) rolls on a side stream, `Tick.Sub(name)`, derived from the seed, the day and the name, so a run that never leaves Eastside replays exactly as it did before the second city existed and every seed-pinned balance number survived #30 unchanged. Keep it that way: a sim that adds dice for the second city draws them from a `Sub`, and so does the law (`Tick.Sub("law")` for an election and a new chief), so the home stream survived #41 too.
